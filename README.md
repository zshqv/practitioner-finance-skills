# practitioner-finance-skills

> Pulling Claude out of the classroom and into the deal room.

Open-source Claude skills focused on practitioner judgment — 
the gap between what Claude knows and how a senior finance 
professional actually thinks.

## Why this exists

Claude handles finance well at the computation layer. 
It computes ratios, lists metrics, explains definitions correctly.

What it does not do by default is think like a practitioner — 
read a deal situation, teach financial concepts through logic 
rather than mechanics, or apply the judgment that comes from 
experience rather than text.

These skills fill that gap.

## Skills

| Skill | What it fixes |
|-------|--------------|
| [finance:deal-read](./finance-deal-read) | Claude lists ratios. This skill reads deals — entry price, capital structure stress, thesis credibility, red flags. |
| [finance:three-statement-intuition](./finance-three-statement-intuition) | Tutorials show you how. This skill teaches you why — logic before mechanics, mentor before textbook. |

## Principles

Skills in this repo are only added when three things are true:
1. The gap was identified from a real experience, not invented
2. A practicing finance professional would recognise the problem immediately
3. Nothing on GitHub already does this well
